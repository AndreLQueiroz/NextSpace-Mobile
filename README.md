# 🚀 NextSpace

> Dashboard mobile para monitoramento climático com dados espaciais simulados.

O **NextSpace** é um aplicativo desenvolvido em **React Native + Expo** com foco em prevenção de desastres naturais através da simulação de dados climáticos inspirados em tecnologias espaciais e monitoramento orbital.

A solução centraliza informações de temperatura, chuva e umidade para gerar alertas inteligentes e visualizar riscos ambientais em tempo real.

---

# 🌍 Contexto do Projeto

O projeto foi desenvolvido para a **Global Solution 2026.1** da disciplina de **Mobile Development & IoT**.

O objetivo da GS é criar uma solução conectada ao ecossistema espacial e seus impactos na Terra, utilizando tecnologia mobile para apresentar dashboards, monitoramento e análise de dados.

O NextSpace utiliza o conceito de:
- Monitoramento orbital
- Dados climáticos simulados
- Prevenção de desastres naturais
- Visualização de risco ambiental

# ⚙️ Como Executar

## 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/nextspace.git
```

---

## 2. Entre na pasta do projeto

```bash
cd NextSpace
```

---

## 3. Instale as dependências

```bash
npm install
```

---

## 4. Execute o projeto

```bash
npx expo start
```
